What is CSS?

Cascading Style Sheets — the language of visual design on the web

🎨

Why CSS?

HTML defines structure. CSS defines appearance. Without CSS, every website would be plain black text on a white background. CSS lets you control layout, color, fonts, animation, responsiveness — everything visual.

🔧

When to Use

  • Style HTML elements (color, font, size)
  • Control layout (flexbox, grid)
  • Create animations and transitions
  • Make responsive designs
  • Apply themes and brand identity
🅰️

CSS in Angular

Angular supports plain CSS, SCSS (Sass), and Less per component. Each component has its own stylesheet that is automatically scoped — styles don't leak between components.

CSS3 vs CSS2

CSS3 is the modern version. It adds variables, animations, flexbox, grid, gradients, transforms, filters, and much more. All modern browsers support CSS3. In this guide, "CSS" means CSS3 unless stated otherwise.

Syntax & Selectors

Targeting elements precisely — the foundation of all CSS

selector
h1 {
  color : #2563eb ;
  font-size : 2rem ;
}
property value

All Selector Types

Universal
* { margin: 0; }

Selects every element. Use for CSS resets.

⚠️ Use carefully — affects performance
Element
p { color: #333; }

Selects all <p> tags. Low specificity.

✅ Good for base typography styles
Class
.btn { padding: 8px; }

Selects elements with class="btn". Most common selector.

✅ Use classes for reusable styles
ID
#header { ... }

Selects element with id="header". Very high specificity.

⚠️ Avoid in components — use classes
Attribute
[type="text"] { ... }

Selects elements by attribute value.

✅ Great for form inputs
Descendant
.card p { ... }

Selects <p> inside any .card at any depth.

✅ Common for layout components
Child >
.nav > li { ... }

Only direct children, not nested.

✅ Safer than descendant
Adjacent +
h2 + p { ... }

Selects <p> immediately after h2.

✅ Typography spacing patterns
Sibling ~
h2 ~ p { ... }

All <p> siblings after h2.

✅ CSS-only state tricks

Angular-Specific Selectors

// component.scss — scoped to this component only
.btn { padding: 12px 24px; }  // only affects THIS component's .btn

// SCSS nesting (Angular uses SCSS by default)
.card {
  padding: 16px;

  &__title { font-size: 1.5rem; }  // .card__title
  &__body  { color: #666; }        // .card__body

  &:hover  { box-shadow: 0 8px 32px rgba(0,0,0,.12); }
  &--large { padding: 32px; }      // .card--large modifier
}
// :host = the component's own element tag
// e.g. if selector is 'app-card', :host = 

:host {
  display: block;          // Components are inline by default!
  width: 100%;
}

:host(.featured) {         // Conditional on parent passing a class
  border: 2px solid gold;
}

:host-context(.dark-theme) {  // When ancestor has dark-theme class
  background: #1a1a2e;
  color: white;
}
// ::ng-deep — override child component styles
// USE SPARINGLY — it breaks encapsulation

// Scenario: you use Angular Material and need to style its internals
::ng-deep .mat-button {
  border-radius: 8px !important;
}

// Better: combine with :host to scope it
:host ::ng-deep .mat-form-field {
  width: 100%;
}

// Enterprise note: prefer theme overrides or CSS vars
// over ::ng-deep wherever possible

⚠️ The !important Nuclear Option

!important overrides ALL specificity. In enterprise Angular, avoid it — use it as a last resort only. Prefer increasing specificity with an extra class or :host scope. Excessive !important creates unmaintainable CSS.

/* Cascade order (highest wins): */
/* 1. !important                    */
/* 2. Inline styles                 */
/* 3. ID selectors                  */
/* 4. Class, attribute, pseudo-class*/
/* 5. Element, pseudo-element       */
/* 6. Source order (last rule wins) */

p { color: blue; }           /* specificity: (0,0,0,1) */
.text { color: red; }        /* specificity: (0,0,1,0) — wins */
#main .text { color: green;} /* specificity: (0,1,1,0) — wins */

/* Angular tip: avoid deep selectors */
/* BAD:  div > section > article > .card { } */
/* GOOD: .card { } in the card's own stylesheet */

The Box Model

Every element is a box — understanding how space is calculated

margin
border
padding
content
width × height
/* Default (content-box): */
/* Total width = width + padding-left + padding-right + border-left + border-right */
.box {
  width: 200px;
  padding: 20px;
  border: 4px solid #333;
  /* Actual rendered width = 200 + 40 + 8 = 248px ← CONFUSING! */
}
/* border-box: width INCLUDES padding and border */
/* This is what every developer actually wants */
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 4px solid #333;
  /* Actual rendered width = exactly 200px ← PREDICTABLE! */
}

/* Apply to everything (universal reset): */
*, *::before, *::after {
  box-sizing: border-box;  /* Do this in every project */
}
/* styles.scss — global Angular reset */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

html {
  font-size: 16px; /* 1rem = 16px */
  -webkit-text-size-adjust: 100%;
}

body {
  line-height: 1.5;
  font-family: var(--font-body); /* use CSS variable */
  color: var(--color-text);
}

img, video {
  max-width: 100%;
  display: block;
}

/* This reset goes in src/styles.scss — applies globally */

@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap');

@font-face {
  font-family: 'MyFont';
  src: url('/assets/fonts/myfont.woff2') format('woff2'),
       url('/assets/fonts/myfont.woff')  format('woff');

/* Fluid typography — scales smoothly between viewport sizes */
/* clamp(min, preferred, max) */

h1 { font-size: clamp(1.75rem, 5vw, 4rem); }
h2 { font-size: clamp(1.4rem, 3.5vw, 2.5rem); }

/* Formula: clamp(min, (viewport_reference * slope + intercept), max) */

/* Angular + SCSS: define a fluid() mixin */
@mixin fluid-type($min, $max) {
  font-size: clamp(#{$min}, 3vw + 0.5rem, #{$max});
}

.hero-title { @include fluid-type(2rem, 5rem); }
.body-text  { @include fluid-type(0.9rem, 1.1rem); }

Display & Visibility

block, inline, flex, grid, none — the foundation of layout

display: block
Block 1
Block 2
Block 3

Each element takes full width. Stacks vertically. <div>, <p>, <h1> are block by default.

display: inline
Inline 1 Inline 2 Inline 3

Flows like text. Cannot set width/height. <span>, <a>, <strong> are inline.

display: inline-block
IB 1
IB 2
IB 3

Flows inline but accepts width/height. Useful for buttons and badges.

display: none vs visibility: hidden
Visible
display:none
vis:hidden
After

display:none removes from layout. visibility:hidden hides but keeps space.

/* Angular *ngIf vs CSS visibility */

// *ngIf removes element from DOM entirely
// [style.display] toggles display:none

isVisible = true;

// Template:
// <div *ngIf="isVisible">   ← DOM removal
// <div [class.hidden]="!isVisible">  ← CSS hide

// Component SCSS:

  visibility: hidden;   // keeps layout space
  // or:
  display: none;        // collapses layout space
  // or:
  opacity: 0;           // invisible but interactive
  pointer-events: none; // + non-interactive
}

Normal flow

Moves from its natural position. Original space is preserved in flow. Used as parent anchor for absolute children.

position: absolute
Normal flow
top:0
right:0
Gaps here

Removed from flow. Positioned relative to nearest positioned ancestor (relative/absolute/fixed). Used for badges, dropdowns, tooltips.

Scroll content

Flexbox

The one-dimensional layout system — rows and columns made simple

Flex Container (display: flex)
← main axis →
Item 1
Item 2
Item 3
↕ cross axis
.container {
  display: flex;                   /* or inline-flex */

  /* Direction */
  flex-direction: row;             /* row | row-reverse | column | column-reverse */

  /* Wrapping */
  flex-wrap: nowrap;               /* nowrap | wrap | wrap-reverse */

  /* Shorthand: direction + wrap */
  flex-flow: row wrap;

  /* Main axis alignment (horizontal by default) */
  justify-content: flex-start;    /* flex-start | flex-end | center | space-between | space-around | space-evenly */

  /* Cross axis alignment (vertical by default) */
  align-items: stretch;            /* stretch | flex-start | flex-end | center | baseline */

  /* Multi-line cross alignment */
  align-content: flex-start;       /* same values as justify-content */

  /* Spacing between items */
  gap: 16px;                       /* Modern, preferred over margins */
  row-gap: 16px;
  column-gap: 24px;
}
.item {
  /* flex-grow: how much to grow when space available */
  flex-grow: 0;     /* default: don't grow */
  flex-grow: 1;     /* take 1 share of remaining space */
  flex-grow: 2;     /* take twice as much as flex-grow: 1 */

  /* flex-shrink: how much to shrink when space is tight */
  flex-shrink: 1;   /* default: shrink equally */
  flex-shrink: 0;   /* never shrink — useful for icons */

  /* flex-basis: initial main axis size */
  flex-basis: auto; /* default */
  flex-basis: 200px;
  flex-basis: 25%;

  /* Shorthand: grow shrink basis */
  flex: 1;           /* 1 1 0%     — most common, equal columns */
  flex: 0 0 200px;   /* fixed 200px, no grow/shrink */
  flex: auto;        /* 1 1 auto   */

  /* Override container alignment for this item */
  align-self: flex-end;

  /* Order (default 0) */
  order: -1;  /* appear before others */
  order: 1;   /* appear after others */
}
/* 1. Perfect centering */
.center { display: flex; justify-content: center; align-items: center; }

/* 2. Space-between header (logo left, actions right) */
.header { display: flex; justify-content: space-between; align-items: center; }

/* 3. Equal columns */
.cols-3 { display: flex; gap: 24px; }
.cols-3 > * { flex: 1; }

/* 4. Sidebar + main layout */
.layout { display: flex; min-height: 100vh; }
.sidebar { flex: 0 0 280px; }  /* fixed width */
.main { flex: 1; overflow: auto; }

/* 5. Sticky footer */
.page { display: flex; flex-direction: column; min-height: 100vh; }

/* 6. Cards that fill remaining height */

.card { flex: 1 1 300px; display: flex; flex-direction: column; }
.card__body { flex: 1; }  /* expands to fill */
.card__footer { margin-top: auto; }

CSS Grid

Two-dimensional layouts — rows AND columns simultaneously

.grid {
  display: grid;

  /* Define columns */
  grid-template-columns: 200px 1fr 1fr;      /* fixed + 2 equal */
  grid-template-columns: repeat(3, 1fr);      /* 3 equal columns */
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); /* responsive! */
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));  /* collapses empty */

  /* Define rows */
  grid-template-rows: auto 1fr auto;          /* header, content, footer */
  grid-auto-rows: 200px;                      /* implicit rows */
  grid-auto-rows: minmax(100px, auto);

  /* Gaps */
  gap: 24px;
  column-gap: 24px;
  row-gap: 16px;

  /* Alignment of ALL items */
  justify-items: stretch;   /* horizontal: start|end|center|stretch */
  align-items: stretch;     /* vertical:   start|end|center|stretch */

  /* Alignment of grid within container */
  justify-content: start;
  align-content: start;
}
.item {
  /* Span columns: start / end (1-based) */
  grid-column: 1 / 3;        /* from column line 1 to 3 = spans 2 cols */
  grid-column: 1 / -1;       /* from first to last line (full width) */
  grid-column: span 2;        /* span 2 columns from current position */

  /* Span rows */
  grid-row: 1 / 3;            /* spans 2 rows */
  grid-row: span 2;

  /* Shorthand: row-start / column-start / row-end / column-end */
  grid-area: 1 / 1 / 3 / 3;

  /* Individual item alignment */
  justify-self: center;
  align-self: end;
}
/* Named template areas — visually maps the layout */
.page {
  display: grid;
  grid-template-areas:
    "header  header  header"

@Injectable({ providedIn: 'root' })
export class ThemeService {
  private root = document.documentElement;

  setColor(name: string, value: string): void {
    this.root.style.setProperty(`--color-${name}`, value);
  }

  getColor(name: string): string {
    return getComputedStyle(this.root)
      .getPropertyValue(`--color-${name}`).trim();
  }

  // Apply full theme object
  applyTheme(theme: Record): void {
    Object.entries(theme).forEach(([key, val]) => {
      this.root.style.setProperty(key, val);
    });
  }
}

@Injectable({ providedIn: 'root' })
export class ThemeService {
  private current$ = new BehaviorSubject<string>('light');
  readonly theme$ = this.current$.asObservable();

  setTheme(theme: string): void {
    document.documentElement.setAttribute('data-theme', theme);
    this.current$.next(theme);
    localStorage.setItem('theme', theme);
  }

  init(): void {
    const saved = localStorage.getItem('theme');
    const system = matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
    this.setTheme(saved ?? system);
  }
}

CSS Performance

Writing CSS that doesn't slow down the browser

✅ GPU-Accelerated Properties

Only these properties trigger compositing (no layout recalculation):

  • transform: translate/rotate/scale
  • opacity
  • filter

Use will-change: transform to hint the browser for complex animations.

⚠️ Layout-Triggering Properties

These force browser to recalculate layout (expensive):

  • width, height, top, left
  • margin, padding, border-width
  • font-size, line-height
  • display changes

Animate with transform instead of top/left.

/* ❌ Slow — triggers layout on every frame */
@keyframes bad-slide {
  from { left: -100px; }
  to   { left: 0; }
}

/* ✅ Fast — GPU accelerated, no layout */
@keyframes good-slide {
  from { transform: translateX(-100px); }
  to   { transform: translateX(0); }
}

/* ✅ Angular: prefer transform-based animations */
/* In Angular Animation API */
transition('* => visible', [
  style({ transform: 'translateY(-20px)', opacity: 0 }),
  animate('200ms ease-out', style({ transform: 'translateY(0)', opacity: 1 }))
]),

/* will-change: tells browser to prepare a layer */
.animated-card {
  will-change: transform; /* use ONLY on elements that WILL animate */
  /* ⚠️ Don't add to everything — wastes GPU memory */
}

/* Contain layout: scope repaints */
.widget {
  contain: layout;    /* layout changes don't affect outside */
  contain: strict;    /* maximum containment */
}

/* content-visibility: skip off-screen rendering (huge perf win) */
.long-list-item {
  content-visibility: auto;
  contain-intrinsic-size: 0 200px; /* estimated height */
}
