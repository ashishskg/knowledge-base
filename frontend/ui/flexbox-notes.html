Basics & mental model

Main axis vs cross axis; container vs items.

Flex container = the parent with display: flex.
Flex items = direct children of the container.
Main axis depends on flex-direction. Cross axis is perpendicular.

display: flex

Turns the parent into a flex container (items line up in a row by default).

CodeHTML + CSS
<div class="row">
  <div class="box">1</div>
  <div class="box">2</div>
  <div class="box">3</div>
</div>

.row { display: flex; gap: 10px; }
.box { width: 60px; height: 50px; background: #111; color: #fff; display: grid; place-items: center; border-radius: 12px; }
Output

display: inline-flex

Like flex, but the container behaves like inline content (shrinks to content width).

CodeHTML + CSS
<p>Before <span class="pill">...
</span> After</p>

.pill { display: inline-flex; gap: 8px; padding: 10px; border-radius: 999px; border: 1px solid #ddd; }
.dot { width: 10px; height: 10px; border-radius: 50%; background: #7ad6ff; }
Output

Flex container properties

These go on the parent (container).

flex-direction

Controls the main axis direction: row, row-reverse, column, column-reverse.

CodeTry switching row/column
.wrap { display: flex; flex-direction: row; gap: 10px; }

/* Try: column */
Output

flex-wrap

Controls whether items wrap onto multiple lines: nowrap (default), wrap, wrap-reverse.

Codewrap vs nowrap
.row { display: flex; flex-wrap: wrap; gap: 10px; }
.item { width: 120px; }
Output

justify-content

Aligns items along the main axis: flex-start, center, flex-end, space-between, space-around, space-evenly.

CodeTry center / space-between
.row { display: flex; justify-content: space-between; }
/* Also try: center */
Output

align-items

Aligns items along the cross axis: stretch (default), flex-start, center, flex-end, baseline.

CodeTry center / baseline
.row { display: flex; align-items: baseline; gap: 10px; }
Output

gap

Sets spacing between items (use instead of margins between children).

CodeClean spacing
.row { display: flex; gap: 16px; }
Output

align-content

Aligns lines in a multi-line flex container (only works with wrapping + extra space). Try: stretch, center, space-between.

CodeNeeds wrap + height
.wrap { display: flex; flex-wrap: wrap; align-content: space-between; height: 160px; }
Output

flex-flow

Shorthand for flex-direction + flex-wrap.

CodeShorthand
.row { display: flex; flex-flow: row wrap; gap: 10px; }
Output

Flex item properties

These go on the children (items).

flex-grow

How much an item grows to fill available free space (relative to siblings).

Code2 grows more than 1
.a { flex-grow: 1; }
.b { flex-grow: 2; }
.c { flex-grow: 1; }
Output

flex-shrink

How items shrink when the container is too small. Set to 0 to prevent shrinking.

CodePrevent shrink
.noShrink { flex-shrink: 0; width: 180px; }
.shrink { flex-shrink: 1; width: 180px; }
Output

flex-basis

The item’s initial size before free space is distributed. Often combined with flex-grow.

CodeBasis sets starting width
.item { flex: 1 1 140px; }
/* grow shrink basis */
Output

flex shorthand

Shorthand: flex: grow shrink basis. Common patterns: flex: 1, flex: 0 0 auto.

Codeflex: 1 vs fixed
.fill { flex: 1; }
.fixed { flex: 0 0 120px; }
Output

order

Reorders items visually (does not change DOM order). Use carefully for accessibility.

CodeMove C to front
.c { order: -1; }
Output

align-self

Overrides align-items for a single item.

CodeOne item moves
.row { align-items: flex-start; }
.b { align-self: flex-end; }
Output

margin-left: auto

A practical trick: use auto margins to push items away (common in navbars).

CodePush right
.row { display: flex; }
.right { margin-left: auto; }
Output

Advanced / edge cases

Min-width, overflow, equal heights, nested flex.

min-width: 0 (important)

In flex layouts, long content can overflow. Setting min-width: 0 on the flexible item allows it to shrink.

CodeFix overflow
.row { display: flex; }
.content { flex: 1; min-width: 0; }
/* Without min-width:0, text may overflow */
Output

Equal height cards

Flex makes equal-height columns easy (items stretch by default on the cross axis).

CodeStretch
.row { display: flex; gap: 10px; }
.card { flex: 1; }
/* Default align-items: stretch */
Output

Nested flex layouts

Flex inside flex: common in real UIs (sidebar layout + toolbar rows).

CodeLayout inside layout
.app { display: flex; }
.sidebar { flex: 0 0 120px; }
.main { flex: 1; display: flex; flex-direction: column; }
Output

flex vs width

If both are set, flex-basis often wins for the base size. Prefer using flex for flex items sizing.

CodePrefer flex-basis
.item { flex: 0 1 160px; }
/* Think: basis is the starting size */
Output

Practical UI patterns

Patterns you’ll build constantly.

Navbar with right-aligned CTA

Combine display:flex, gap, and margin-left:auto.

CodeNavbar
.nav { display: flex; gap: 10px; align-items: center; }
.cta { margin-left: auto; }
Output

Sticky footer (page layout)

Make the body a column flex container and push footer down with flex:1.

CodeColumn layout
body { min-height: 100vh; display: flex; flex-direction: column; }
main { flex: 1; }
Output

Responsive card row (wrap)

Use flex-wrap: wrap and a basis like 220px.

CodeResponsive cards
.row { display: flex; flex-wrap: wrap; gap: 10px; }
.card { flex: 1 1 220px; }
Output

Media object (icon + text)

A classic pattern: fixed media + flexible content using gap and min-width:0.

CodeIcon + content
.row { display: flex; gap: 12px; }
.icon { flex: 0 0 44px; }
.content { flex: 1; min-width: 0; }
Output

Debug & learning checklist

How to avoid the most common Flexbox confusion.

1) Identify container vs items: Flexbox properties apply either to the parent or the children, not both.
2) Decide main axis by checking flex-direction.
3) Use gap for spacing between items.
4) When text overflows in a flex item, add min-width: 0 to the flexible item.
5) For two-dimensional card layouts, prefer CSS Grid. Use Flexbox for rows/columns.
