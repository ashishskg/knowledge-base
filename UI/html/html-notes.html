HTML Tags Notes (Modern)

Category-wise notes for common modern HTML tags. Each card shows what the tag is for, a minimal example, and a small demo preview.

Document skeleton

Core structure tags.

<!doctype html>

Declares the document as HTML5 so browsers use standards mode.

ExampleDeclaration
<!doctype html>
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

Demo

This tag is a declaration and doesn’t render visible content.

<html>

Root element that wraps the entire HTML document.

ExampleRoot
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

Demo

Root wrapper (not directly visible).

<head>

Contains metadata, styles, title, and other resources for the document.

ExampleMetadata container
<head>
  <meta charset="utf-8" />
  <title>My Page</title>
</head>

Demo

Not directly visible on the page.

<body>

Contains all visible content of the page.

ExampleContent container
<body>
  <h1>Hello</h1>
  <p>Visible content lives here.</p>
</body>

Demo

Hello

Visible content lives here.

Metadata

Head-only tags that describe the document.

<title>

Sets the browser tab title and the page title used by bookmarks/search.

ExampleHead
<head>
  <title>HTML Notes</title>
</head>

Demo

See your browser tab title.

<meta>

Defines metadata such as charset, viewport, description, and more.

ExampleHead
<meta charset="utf-8" />
<meta name="viewport" content="width=device-width, initial-scale=1" />

Demo

Not directly visible; affects encoding & responsive layout.

<link>

Links external resources like stylesheets and icons.

ExampleHead
<link rel="stylesheet" href="styles.css" />
<link rel="icon" href="favicon.ico" />

Demo

Not directly visible; affects styling and icons.

<base>

Sets a base URL for relative links in the document (use carefully).

ExampleHead
<base href="https://example.com/" />
<a href="docs">Docs</a>

Demo

Affects how relative URLs resolve.

Scripting & styling hooks

Load scripts and define fallback content.

<style>

Embeds CSS directly in the document.

ExampleCSS
<style>
  .note { color: teal; }
</style>
<p class="note">Styled text</p>

Demo

Styled text (in-page)

<script>

Adds JavaScript either inline or via a linked file.

ExampleJS
<button id="btn">Click</button>
<script>
  document.getElementById('btn').addEventListener('click', () => {
    alert('Hello');
  });
</script>

Demo

Scripts run in the browser (open this file to test).

<noscript>

Content shown when JavaScript is disabled or unsupported.

ExampleFallback
<noscript>
  <p>This site works best with JavaScript enabled.</p>
</noscript>

Demo

Turn off JS to see it in action.

Media

Images, responsive images, and audio/video.

<img>

Embeds an image. Always include meaningful alternative text.

ExampleImage
<img src="photo.jpg" alt="A sunset over the ocean" />

Demo

(Image demo depends on a real file path.)

<picture> and <source>

Provides responsive images with multiple sources; browser picks the best match.

ExampleResponsive
<picture>
  <source media="(min-width: 800px)" srcset="large.jpg" />
  <img src="small.jpg" alt="A mountain" />
</picture>

Demo

(Requires actual image files.)

<audio>

Embeds audio playback controls.

ExampleAudio
<audio controls>
  <source src="song.mp3" type="audio/mpeg" />
</audio>

Demo

(Requires a real audio file.)

<video> and <track>

Embeds video playback; <track> can provide captions/subtitles.

ExampleVideo
<video controls width="320">
  <source src="clip.mp4" type="video/mp4" />
  <track kind="captions" src="captions.vtt" srclang="en" label="English" />
</video>

Demo

(Requires a real video file.)

<figure> and <figcaption>

Wraps media or code examples with an optional caption.

ExampleCaption
<figure>
  <img src="diagram.png" alt="Architecture diagram" />
  <figcaption>System architecture</figcaption>
</figure>

Demo

Embedding

Embed other documents or external content.

<iframe>

Embeds another HTML page within the current page.

ExampleFrame
<iframe src="https://example.com" title="Example site"></iframe>

Demo

(Embedding external sites may be blocked by security headers.)

<embed>

Embeds an external resource (often plugins/documents); use when appropriate.

ExampleResource
<embed src="file.pdf" type="application/pdf" />

Demo

(Requires a real file and browser support.)

<object> and <param>

Embeds an external resource; <param> provides parameters to the resource.

ExampleObject
<object data="file.pdf" type="application/pdf">
  <param name="view" value="FitH" />
  <p>PDF could not be displayed.</p>
</object>

Demo

Fallback content can show if embedding fails.

Tables

Tabular data: headings, rows, body, footers.

<table> family

Use tables for data (not layout). Combine <caption>, head/body/foot, and header cells for accessibility.

ExampleTable
<table>
  <caption>Scores</caption>
  <thead>
    <tr><th>Name</th><th>Score</th></tr>
  </thead>
  <tbody>
    <tr><td>Asha</td><td>95</td></tr>
    <tr><td>Ravi</td><td>88</td></tr>
  </tbody>
</table>

Demo

Forms

Collect user input: fields, choices, and feedback.

<form>

Wraps input controls that can be submitted to a server.

ExampleForm
<form>
  <label>Name <input /></label>

</form>

Demo

<label>

Labels an input control; improves usability and accessibility.

ExampleLabel
<label for="email">Email</label>
<input id="email" type="email" />

Demo

<input>

Single-line input. The type changes behavior (text, email, password, date, file, etc.).

ExampleInput
<input type="text" placeholder="Your name" />
<input type="password" placeholder="Password" />
<input type="date" />

Demo

<textarea>

Multi-line text input.

ExampleTextarea
<textarea rows="3" cols="30">Write here...</textarea>

Demo

<button>

Clickable button (submit/reset/button). Prefer this over clickable divs.

ExampleButton
<button type="button">Click me</button>

Demo

Dropdown selection with options (optionally grouped).

<output>

Represents the result of a calculation or user action.

ExampleResult
<form oninput="result.value = Number(a.value) + Number(b.value)">
  <input id="a" type="number" value="2" /> +
  <input id="b" type="number" value="3" /> =
  <output name="result">5</output>
</form>

Demo

+ = 5

Disclosure / interactive

Built-in interactive HTML elements.

<details> and <summary>

Creates a disclosure widget: click summary to show/hide details.

ExampleDisclosure
<details>
  <summary>More info</summary>
  <p>Hidden content.</p>
</details>

Demo

More info

Hidden content.

<dialog>

Native dialog/modal element. You can open it with JavaScript (showModal()).

ExampleDialog
<button id="open">Open</button>
<dialog id="dlg">
  <p>Hello!</p>
  <button id="close">Close</button>
</dialog>
<script>
  open.onclick = () => dlg.showModal();
  close.onclick = () => dlg.close();
</script>

Demo

Dialog needs JS to open; example shows the pattern.
